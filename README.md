# Calorie Tracker

A **Java-based console application** for tracking daily food intake, calories, and macronutrients. It also calculates BMI and personalized calorie, protein, carbohydrate, and fat goals based on user information.

## Features

* Calculate **BMI and BMI category**
* Set personalized **calorie & macronutrient goals**
* Track daily food intake
* Built-in Indian food database
* Add custom food items
* Edit food quantities
* Remove food entries
* View daily and multi-day food logs
* Track calorie and macro totals
* Basic streak tracking

## Tech Stack

* **Java**
* Object-Oriented Programming (OOP)
* Arrays & Classes
* Java `Scanner` for console input

## Run Locally

```bash
git clone https://github.com/YOUR-USERNAME/Calorie-Tracker.git
cd Calorie-Tracker
javac CalorieTracker.java
java CalorieTracker
```
